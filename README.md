# Darts Career

Karrieremodus für Darts im FIFA-Stil – Browserspiel ohne Backend (HTML/CSS/JS, ES-Module).

**Start lokal:** im Projektordner `python3 -m http.server` ausführen und http://localhost:8000 öffnen
(ES-Module funktionieren nicht per Doppelklick/`file://`). Läuft auch direkt auf GitHub Pages.

**Tests:** `node tests/run.mjs`

> Hinweis: Fanprojekt, nur zur privaten Nutzung. Spätere Versionen verwenden echte Spielernamen ohne Lizenz.

Entwicklungsstand: siehe `STATUS.md`. Projektregeln: siehe `CLAUDE.md`.
